# Amazon.in Clone — Functional Update

## Run in VS Code
1. Extract this ZIP.
2. Open the `MiniProject` folder in VS Code.
3. Open Terminal in that folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the localhost URL shown in the terminal.

## Working features
- Home, All Products, Best Sellers, Today's Deals, Electronics, Fashion, Home & Kitchen, About/Help, Cart, Checkout, Order Confirmation and Orders pages.
- Search and category filters.
- Product details modal and add-to-cart.
- Cart quantity controls, remove item and subtotal.
- Proceed to Buy opens checkout; checkout validates fields and PIN code.
- Place Order displays a confirmation and saves the most recent order.
- Cart and last order persist in browser local storage.

Checkout is a project demonstration only. It does not process real payments.
